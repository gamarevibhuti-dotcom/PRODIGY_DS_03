# PRODIGY_DS_03 - Decision Tree Classifier

## 📌 Objective
Build a Decision Tree Classifier to predict whether a customer will purchase a product or service using the Bank Marketing dataset.

---

## 📂 Dataset
- **Dataset:** Bank Marketing Dataset
- **Source:** UCI Machine Learning Repository
- **Records:** 4,521
- **Features:** 17

---

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

---

## 📋 Steps Performed
- Imported required libraries
- Loaded and explored the dataset
- Checked for missing values
- Encoded categorical variables using LabelEncoder
- Split the dataset into training and testing sets
- Built a Decision Tree Classifier
- Made predictions on the test data
- Evaluated the model using:
  - Accuracy Score
  - Confusion Matrix
  - Classification Report
- Analyzed feature importance

---

## 📊 Model Performance
- **Algorithm:** Decision Tree Classifier
- **Accuracy:** **87%**

---

## 📈 Results
The Decision Tree Classifier successfully predicted whether a customer would subscribe to a product or service. The model achieved an accuracy of **87%**, demonstrating good predictive performance on the Bank Marketing dataset.
